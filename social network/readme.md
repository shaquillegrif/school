# Projectnaam

Modenre hyves

# Omschrijving

Een eigen remake van het vroegere Nederlandse sociale netwerk **Hyves**, gebouwd als modern webdevelopmentproject met _HTML_, _CSS_ en _JavaScript_.

Het doel van dit project is om de belangrijkste onderdelen van een sociaal netwerk uit de Hyves-periode opnieuw te bouwen, maar met een eigen ontwerp en moderne webtechnieken.

## Projectdoel

Het project bestaat uit een sociale netwerkwebsite waarin gebruikers onder andere:

1. Een account kunnen registreren
2. Kunnen inloggen en uitloggen
3. Een eigen profiel kunnen maken
4. Een profielfoto kunnen instellen
5. Andere gebruikers kunnen zoeken
6. Vrienden kunnen toevoegen
7. Vriendschapsverzoeken kunnen accepteren
8. Krabbels kunnen plaatsen
9. Foto's kunnen uploaden
10. Een overzicht van recente activiteiten kunnen bekijken

De website krijgt een retro-uitstraling geïnspireerd op sociale media uit de jaren 2000, maar gebruikt een eigen naam, logo en vormgeving.
