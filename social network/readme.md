Een eigen remake van het vroegere Nederlandse sociale netwerk Hyves, gebouwd als modern webdevelopmentproject met HTML, CSS en JavaScript.

Het doel van dit project is om de belangrijkste onderdelen van een sociaal netwerk uit de Hyves-periode opnieuw te bouwen, maar met een eigen ontwerp en moderne webtechnieken.

Projectdoel

Het project bestaat uit een sociale netwerkwebsite waarin gebruikers onder andere:

Een account kunnen registreren
Kunnen inloggen en uitloggen
Een eigen profiel kunnen maken
Een profielfoto kunnen instellen
Andere gebruikers kunnen zoeken
Vrienden kunnen toevoegen
Vriendschapsverzoeken kunnen accepteren
Krabbels kunnen plaatsen
Foto's kunnen uploaden
Een overzicht van recente activiteiten kunnen bekijken

De website krijgt een retro-uitstraling geïnspireerd op sociale media uit de jaren 2000, maar gebruikt een eigen naam, logo en vormgeving.
